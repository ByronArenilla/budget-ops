# Specs

Cada carpeta `NNN-nombre/` contiene:

- `spec.md`: el QUÉ y el POR QUÉ, con requisitos RF-x en notación EARS.
- `plan.md`: el CÓMO técnico, indicando qué RF cubre cada parte.
- `tasks.md`: tareas pequeñas con checkbox y línea "Hecho cuando:".

El listado completo de specs planeadas está en `../docs/roadmap.md`.
Flujo: spec → clarificación → plan → tareas → implementación → validación.
